# Standardize text fields
transit_df["Agency"] = transit_df["Agency"].str.strip()
transit_df["County"] = transit_df["County"].str.strip()
population_df["County"] = population_df["County"].str.strip()

# Ensure numeric columns are numeric
numeric_cols = ["Annual_Unlinked_Trips", "Operating_Expenses", "Profile_Population"]
for col in numeric_cols:
    transit_df[col] = pd.to_numeric(transit_df[col], errors="coerce")

population_df["County_Population_2024"] = pd.to_numeric(population_df["County_Population_2024"], errors="coerce")

# Blend the datasets
merged_df = pd.merge(transit_df, population_df, on="County", how="left")

# Create derived metrics for deeper analysis
merged_df["Expense_Per_Trip"] = merged_df["Operating_Expenses"] / merged_df["Annual_Unlinked_Trips"]
merged_df["Trips_Per_Resident"] = merged_df["Annual_Unlinked_Trips"] / merged_df["County_Population_2024"]
merged_df["Operating_Expenses_Millions"] = merged_df["Operating_Expenses"] / 1_000_000
merged_df["Trips_Millions"] = merged_df["Annual_Unlinked_Trips"] / 1_000_000

print("\nIntegrated data set preview:\n")
display(merged_df.head())

# Detailed visualization for planners and analysts

# Create a figure with a readable size
plt.figure(figsize=(10, 6))

# Create a scatter plot where:
# x-axis = county population
# y-axis = annual unlinked trips
# bubble size = operating expenses in millions
plt.scatter(
    merged_df["County_Population_2024"],
    merged_df["Annual_Unlinked_Trips"],
    s=merged_df["Operating_Expenses_Millions"] * 5,   # scaled down to avoid oversized bubbles
    alpha=0.7
)

# Add agency labels next to each point
for _, row in merged_df.iterrows():
    plt.annotate(
        row["Agency"],
        (row["County_Population_2024"], row["Annual_Unlinked_Trips"]),
        xytext=(6, 6),
        textcoords="offset points"
    )

# Add chart title and axis labels
plt.title("Ridership, Population, and Operating Expenses")
plt.xlabel("County Population Estimate (2024)")
plt.ylabel("Annual Unlinked Passenger Trips (2023)")

# Add padding around the data so bubbles are not cut off at the edges
x_min = merged_df["County_Population_2024"].min()
x_max = merged_df["County_Population_2024"].max()
y_min = merged_df["Annual_Unlinked_Trips"].min()
y_max = merged_df["Annual_Unlinked_Trips"].max()

plt.xlim(x_min - (x_max * 0.1), x_max * 1.2)
plt.ylim(y_min - (y_max * 0.1), y_max * 1.2)

# Improve spacing so labels and titles fit neatly
plt.tight_layout()

# Display the visualization
plt.show()

Detailed Visualization for Analysts and Planners¶

This scatter plot provides a detailed, multi-variable view of transit performance across agencies. The visualization integrates three key data attributes: county population (x-axis), annual ridership (y-axis), and operating expenses (represented by bubble size). This allows for a deeper analysis of how population size relates to transit usage while also considering cost.

Adjustments were made to the axis ranges and bubble sizes to ensure that all data points are fully visible and not cut off at the edges. This improves clarity and prevents distortion of the data, especially for agencies with significantly higher values.

From this visualization, it is clear that King County Metro serves a substantially larger population and has much higher ridership compared to the other agencies. Spokane Transit Authority falls in the middle, while the City of Longview has significantly lower values across all metrics. This detailed view helps analysts evaluate efficiency, demand, and resource allocation across different transit systems.

Module Three Activity¶

You will complete your assignment code in this Module_Three_Activity.ipynb Notebook file from the filetree that is pre-templated for your modification in accordance with the assignment instructions.

Once your code is complete, you will download this notebook as an HTML file by clicking File, then Download As, then HTML (.html) from the Jupyter menu bar. You will also need to download the csv output file of your merged data. Validate that your code and outputs are rendered in the html file before submission.

Missing Blocks: Ensure that you have clicked Run for all blocks before downloading as an HTML file or the block may be missing from your submission.

Data Source Information¶

The sourcing information for the data sets can be found in the README.md file within the data folder.

To use this starter code file, replace the data/sample_use_only/{data_name}.csv with the reference to your selected data from the list below:

  • data/nyc_temperatures.csv
  • data/nyc_weather_2018.csv
  • data/parsed.csv
  • data/quakes.db
  • data/tsunamis.csv
  • data/weather.db
  • data/weather_by_station.csv
  • data/weather_stations.csv
To Begin: replace each data_file_# entry sample data path with the path to your selected data sets.

If you choose to only use two data files instead of three, comment out the reference to data_file_3.

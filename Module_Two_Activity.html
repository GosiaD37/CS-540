Using Numpy to Find Missing Data using a Dictionary Comprehension¶

Rather than do this for each column, we can write a function that will use a dictionary comprehension to check all the columns for us:

In [ ]:
# Function to count missing (NaN) values in each column using a dictionary comprehension
def get_nan_count(clean_data):
    return {
        col: clean_data[clean_data[col].isin([np.nan])].shape[0]
        for col in clean_data.columns
    }

# Display missing value counts for each column
get_nan_count(clean_data)
